My word for the whole internet: **Receipts**.

Everything online is screenshotted, archived and quoted back at its author forever. Nobody truly deletes anything, apologies arrive with attachments, and every argument is settled by whoever kept the receipts.

[bounty page](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b)

`main.ts` (Node standard library only) writes the word to `/output/entry.txt`.
